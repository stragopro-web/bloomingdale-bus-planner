# Stellar Route – Chania

Independent application, deployed from branch `stellar-route-chania`, root directory `stellar-route`, to the separate Vercel project `stellar-route-chania`.

530 mapped points: 484 urban stops and 46 KTEL points on the western Chania–Kissamos corridor. KTEL points come from its published tourist map and are not an exhaustive, direction-verified stop sequence. The app displays this limitation and links the source.

No changes are required to the original Bloomingdale application on main.
