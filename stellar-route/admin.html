Φόρτωση ρύθμισης…

Χρειάζεται έργο Google Cloud με ενεργό Routes API και χρέωση Google Maps Platform. Το κλειδί αποθηκεύεται ιδιωτικά στον διακομιστή και δεν εμφανίζεται στους επισκέπτες.

Άφησέ το κενό για να διατηρηθεί η υπάρχουσα σύνδεση. Περιόρισε το κλειδί στο Routes API από το Google Cloud.

Η Google μπορεί να χρεώνει τους υπολογισμούς. Η ενεργοποίηση κάνει έναν δοκιμαστικό υπολογισμό για έλεγχο του κλειδιού. Ρύθμισε και τα όρια χρήσης στο Google Cloud.
