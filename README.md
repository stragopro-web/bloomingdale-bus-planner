# Bloomingdale Spa Bus Planner v3

Mobile-first prototype for customers travelling to Bloomingdale Spa from Chania or Kissamos/Kasteli.

Current prototype includes:
- KTEL / Urban Bus operator identity
- Urban line number display
- KTEL route ID and bus number placeholders marked LIVE
- Direction and stop name
- Recommended stop arrival time
- Estimated bus / spa / appointment times
- Green / amber / red connection status

Important: intermediate stop passage times are planning estimates until all stops and live timetable data are verified for production use.
